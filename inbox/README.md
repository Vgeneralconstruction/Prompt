# Inbox — tham khảo viral

Admin ghi mỗi video viral Huynh gửi thành 1 file: `inbox/<YYYY-MM-DD>-<tên-ngắn>.md`

```
nguồn: <nền tảng, ngày>
hook: <0–2s đầu>
cấu trúc: <các cảnh>
text overlay: <...>
audio: <mô tả của Huynh>
vì sao viral: <...>
gợi ý cho VGC: <...>
status: new
```

Agent 01 đọc các file `status: new`, dùng xong đổi thành `status: used (<VIDEO-ID>)`.
